## Studio instructions
Use the professional lockup from the approved partner folder and keep the configuration paragraph on the same panel. A system sans headline is acceptable. Reserve a right-hand image field for the OM commuter portrait, identified in the DAM as ASSET-OM-PORTRAIT. The image binary will be supplied by Production. The name-and-mark grant is referenced in the alliance circular.

The request form was designed to collect dimensions and copy in one pass. “Complete” is the studio's intake status. Reserve the slot in the September production calendar, fit the supplied text and return a scaled PDF proof to the event team. The form team will review additional fields after the first jobs.

Copy fitting and export may proceed as a review proof. Final production is signed through the normal event release route. Keep the job reference in the proof footer and return amendments to Regional Production.
